# Årsredovisnings-RAG

RAG-system (retrieval-augmented generation) som svarar på frågor om årsredovisningar med
källhänvisning (sida/dokument).

## Status

Fas 0 — grund och scope. Se [docs/SCOPE.md](docs/SCOPE.md) och [CLAUDE.md](CLAUDE.md).

## Struktur

- `/data` — årsredovisningar (PDF) och genererad data
- `/src` — applikationskod
- `/tests` — tester
- `/docs` — beslut och scope
