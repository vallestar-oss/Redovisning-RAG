# Scope

## Nyckeltal i scope (12–15 st), med formel

- Omsättning/nettoomsättning
- Rörelseresultat (EBIT)
- EBITDA
- Nettoresultat/årets resultat
- Bruttomarginal = bruttovinst / omsättning
- Rörelsemarginal = rörelseresultat / omsättning
- Vinstmarginal = nettoresultat / omsättning
- EPS / vinst per aktie
- Soliditet = eget kapital / totala tillgångar
- Skuldsättningsgrad = totala skulder / eget kapital
- Kassalikviditet = (omsättningstillgångar − varulager) / kortfristiga skulder
- ROE = nettoresultat / eget kapital
- ROA = nettoresultat / totala tillgångar
- Fritt kassaflöde = operativt kassaflöde − investeringar
- Utdelning per aktie / direktavkastning (endast om aktiekurs matas in separat)

## Frågetyper i scope, prioritetsordning

1. Enårsuppslag ("Vad var omsättningen 2024?")
2. Flerårstrend/YoY ("Hur har soliditeten utvecklats 2022–2024?")
3. Nyckeltalsberäkning som kombinerar poster ("Vad var bruttomarginalen 2024?")
4. Enkla kvalitativa frågor om risker/utsikter från förvaltningsberättelsen

## Explicit utanför scope (v1)

- Marknads-/kursberoende multiplar utan separat kursdata (P/E, P/S, P/B)
- Djupa notberäkningar, segmentrapportering, närståendetransaktioner
- Frågor som kräver att jämföra flera olika bolag mot varandra
- Skannade/OCR-krävande PDF:er och tabeller med hopslagna celler
- Alternativa nyckeltal (APM:er, t.ex. justerat EBITDA) ska inte räknas om av systemet —
  extrahera bolagets egen redovisade siffra istället

## Krav på varje svar

- Källhänvisning till sida/dokument.
- Om svaret inte finns i underlaget ska systemet säga det tydligt, aldrig gissa.
